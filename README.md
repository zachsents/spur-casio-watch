# spur-casio-watch

A live Casio Wave Ceptor (WVA-M630D) face, drawn in SVG: dial, lumed batons, hands and the LCD with weekday and date. A widget only, suggested for Home.

A [Switch](https://switch.ax) spur, built on [spur-kit](https://github.com/zachsents/spur-kit).

## Install

Ask Switch's agent to install `github:zachsents/spur-casio-watch`, or add it in the desktop's Spurs view
(⌘K, Spurs). Switch runs it on the first machine with what it needs.

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
